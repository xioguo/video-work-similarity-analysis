# 原始证据获取与来源核验

## 环境与能力

登记当前能用的平台读取/下载、中文全量转写、Python、Pillow、ffmpeg或imageio-ffmpeg、图像查看能力。工具名称是可替换实现，不假定特定供应商或API必然可用；不在技能内存凭据。缺少工具时在案件blocked_steps记录步骤、实际错误、替代获取途径、仍缺证据。不得绕过平台访问控制。

安装图像与视频依赖可使用公开依赖文件`python3 -m pip install -r requirements.txt`，仅按所在环境授权执行。视频下载可用当前平台支持的工具，例如yt-dlp；遇到不支持的平台可以复用用户提供的本地视频或已核素材，不把“工具不能下载”写成视频内容结论。若要使用额外账号、凭据或付费服务，先遵从用户授权范围。

## 元数据与全量转写

保存标题、作者、发布时间及其时区、简介/标签、访问时间与来源页面；区分上传时间与更早实际创作时间。未知时写未知。

从原视频提取音轨供带时间的中文语音识别使用。保留完整结果和转写服务实际覆盖范围，确认不是只得到开头。同音字校正另存校正版与变更记录；人名/产品名不可凭常识强改。纯文字转写供统一入口核验引文，时间对照保存在标注和原转写中；原始听辨争议须留在限制中。

ffmpeg可用`ffmpeg -i video.mp4 -vn -ar 16000 -ac 1 audio.wav`提取音频。也可用imageio_ffmpeg.get_ffmpeg_exe()取得本机二进制路径。Python调用subprocess参数数组；示例中的路径需替换为真实路径，不照抄占位符。

## 时间线与共同来源

A/B按可核发布时间排序，记录查询词、查询范围、能访问及未覆盖的部分。更早的候选作品须核查具体相同表达或素材，不凭标题认定原发。B之后的页面不能直接证明其之前已公开；如页面指向更早材料，核对原始时间。下架重发可能导致页面时间倒挂。

同一产品投放不证明存在统一脚本，也不证明授权；需要具体brief、脚本、官方素材包或可追溯创作记录。来源分类：F0已核公共/官方、F1题材或步骤必然、F2有具体记录支持的个性来源、unknown未明。来源与授权分别核实，不把“未搜到”当原创证明。

## 画面

使用extract_frames.py取得全长采样清单、全部网格页、原帧指纹。默认5秒；候选连续窗口1秒。target_seconds是定位请求的约时点，不是保证精确的实际帧时间。逐张需要精确定位时另核原始时间，不把文件名当时间。

网页封面与视频首帧不同：无法获得平台封面时写不可获取原因；以首帧辅助展示须明确标为首帧，不冒充封面。

原视频和原始帧保持不变；裁剪、加标、并列图另存。无命中仅说明当前采样未证实，不能排除更短片段或证明独立录制。
